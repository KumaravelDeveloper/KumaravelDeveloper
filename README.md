## 🚀 About Me

I'm an AI Engineer with a strong focus on **applied AI and automation** — I build tools that turn AI models into practical, working products rather than just prototypes. I hold the **Microsoft Azure AI Engineer Associate (AI-102)** certification and enjoy working across the stack: from AI/ML integration and NLP to file systems, developer tooling, and full-stack apps.

I like taking an idea (sometimes inspired by movies, sometimes by a real everyday problem) and shipping it as a working project — from AI coding agents to file search engines to health-tech assistants.
